Carregando…

1. Escolha a direção.
2. Use pincel, borracha ou conta-gotas.
3. Aplique o retoque e salve no jogo.

O arquivo recebe um backup antes de salvar. Com o projeto aberto no Godot, a imagem se atualiza em cerca de um segundo. Executáveis exportados precisam de uma nova exportação.

Montaria

Reinicie o jogo pelo projeto Godot uma vez para ativar esta integração. Depois, os próximos salvamentos atualizam a imagem sem reiniciar.
