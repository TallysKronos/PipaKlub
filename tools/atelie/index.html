Da folha ao passeio

  1. Escolha uma peça na biblioteca e clique no mapa para colocá-la.
  2. Use Piso para arrastar uma área onde Kael pode caminhar. Use Colisão para bloquear uma base.
  3. Em Selecionar, clique e arraste objetos. Ajuste base, apoio e piso nas propriedades.
  4. Importe um PNG e crie recortes na bancada. O arquivo do projeto guarda essas imagens.
  5. Testar com Kael usa as mesmas regras de circulação e profundidade do jogo. Mapas inválidos exibem o motivo.
  6. Salvar arquivo guarda o projeto editável. Exportar gera mapa, arte, atlas, imagens e instruções em ZIP.

V selecionar · B peça · G piso · C colisão · Delete apagar · Ctrl+Z desfazer · Ctrl+Shift+Z refazer. Arraste com o botão do meio para mover a bancada. Esc sai do teste.

A gravação automática usa este navegador. Baixe o projeto para ter uma cópia independente.
