# Origem das peças de tinta

As nove fontes raster de `art/ui/recorte-v1/sources/` foram geradas para este projeto usando a ferramenta integrada `image_gen`, sem inserir arte de franquias de terceiros como referência. Os originais e seus metadados de origem foram preservados. Registro dos arquivos, ferramenta, prompts resumidos e derivados em `art/ui/recorte-v1/provenance.json`.

Os PNGs desta pasta são derivados normalizados dessas fontes. Máscara numérica de transição e retículas alternativas são produzidas pelo script local documentado. Não foi atribuída licença CC0 ou autoria de artista humano a saídas geradas.

As fontes tipográficas pertencem ao kit já existente: Lilita One, Bangers, Barlow Condensed e Nunito. Seus arquivos OFL permanecem em `godot/licenses/`; nenhum arquivo de fonte foi duplicado ou relicenciado nesta tarefa.
