Critérios propostos para este teste

Sem níveis, atributos ou materiais consumidos. Os critérios são uma hipótese de design; marcar caixas não comprova treinamento no jogo.

O que esta família preserva

O mesmo parceiro. Nome pessoal, memória e vínculo continuam na rabiola. Retorno e mudança de rota pela oficina são propostas para avaliar.

As três escolhas existentes. A é Azulfazo de ataque. B é a ave alta de velocidade. C é a ave compacta de inteligência. Nenhuma virou espécie avulsa.

A história de Gollia. A evolução forçada leva ao Azulfazo possuído. Sua derrota desfaz a almática; não libera uma forma purificada para o grupo.

Entrelaço: reservado; nenhum parceiro ou corpo combinado aprovado. Não foi criada fusão para preencher uma vaga.

Novos desenhos: briefs em aberto, sem ilustração inventada por código. Prova documental independente; sem integração ao jogo.
