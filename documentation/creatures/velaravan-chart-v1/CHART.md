# Família Velaravan

Os guias do vento adormecido.

Velim → Dunelo → Velaruta → Velaravan

De pequeno casulo que acompanha passos a condutor de rotas. A corcova guarda faixas que vibram como mapas sonoros. O adulto reduz o ruído da tempestade para o grupo ouvir o próximo marco.

Velim ganha apoios e partes próprias para começar a função de os guias do vento adormecido.

Dunelo desenvolve sustentação e articulações para coordenar essa função em Velaruta.
