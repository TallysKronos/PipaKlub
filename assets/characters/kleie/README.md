# Kleie — spritesheet v1

Primeira versão artística para líder das Trilhas, criada com a ferramenta integrada imagegen. Estilo e grade baseados no spritesheet do Kael. PNG com transparência original preservada.

Grade 4 × 4. Linha 1: repouso/expressões. Linha 2: estudos de caminhada para a direita. Linha 3: controle e puxada de linha. Linha 4: saudação, pensamento, prontidão e vitória.

Revisar margens, pivôs, separação de quadros e continuidade dos ciclos antes de usar como animação final. Folha conceitual: ainda não registrada no atlas, build ou jogo. Não substitui os líderes atuais nem define automaticamente a Trilha de cada personagem.

## Prompt final

Use case: stylized-concept. Asset type: original PipaKlub 2D trail-leader CHARACTER SPRITESHEET. Provided Kael sheet is ONLY the reference for 2D rendering, youthful proportions and sheet layout; create a different original character, not Kael recolored. Create KLEIE, a young teenage MALE ATHLETE inspired by the ACE OF HEARTS playing-card SYMBOL ♥, not by any actor or franchise character. Energetic competitive but friendly, athletic slim build, warm medium-brown skin, dark brown eyes, short curly black hair, sporty ivory headband with a single small red heart. Contemporary athletic outfit: red sleeveless running jersey with ivory side panels and one simple red/ivory heart emblem at chest, navy athletic shorts with red side stripe, white sports socks, red-and-ivory trainers, matching wrist sweatbands. Subtle card-inspired graphic language, NO card costume and no literal cards or weapons. Around four heads tall, matching Kael's young stylized game proportions, distinct curly silhouette. Crisp hand-drawn 2D game art with near-black outlines, flat clean cel shading, compact color clusters, restrained tiny pixel-textured edges as reference; no 3D, no glossy painterly finish. EXACTLY FOUR equal columns by FOUR equal rows with SIXTEEN full-body figures; portrait sheet 1536x2048 if possible with 384x512 cells, same scale, generous transparent margins, identical foot baseline in each row, all bodies fully inside cells. Row 1 four subtle idle frames facing RIGHT in 3/4 view breathing/blinking. Row 2 four consecutive RIGHT-facing walk-cycle poses contact/down/passing/up, athletic alternating legs/opposite arms. Row 3 four empty-handed kite-line control frames facing right: anticipation, reach, strong pull, recovery. Row 4 four expressive poses: welcoming wave, thoughtful hand at chin, athletic ready stance, joyful fist-raised victory. Preserve hair, headband heart, face, physique, outfit and emblem in every cell. Genuine transparent alpha background, no scenery, no grid, no words, no labels, no watermark, no kite or string crossing cells.
