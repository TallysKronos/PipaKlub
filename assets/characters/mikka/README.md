# Mikka — spritesheet v1

Primeira versão artística para líder das Trilhas, criada com a ferramenta integrada imagegen. Estilo e grade baseados no spritesheet do Kael. PNG com transparência original preservada.

Grade 4 × 4. Linha 1: repouso/expressões. Linha 2: estudos de caminhada para a direita. Linha 3: controle e puxada de linha. Linha 4: saudação, pensamento, prontidão e vitória.

Registrada no atlas principal, no build e na lista de imagens do servidor. Usada como líder nas Trilhas, em poses estáticas de apresentação, prontidão e vitória. Revisar a continuidade da caminhada antes de usá-la como ciclo de locomoção; essa animação não é necessária ao uso atual. Kael permanece fora da integração.

Use case: stylized-concept. Asset type: original PipaKlub 2D trail-leader CHARACTER SPRITESHEET. The provided Kael spritesheet is ONLY a rendering, proportions and layout reference; do not copy his identity, hair or costume. Create MIKKA, a young teenage girl, warm imaginative adventurous personality loosely inspired by Anne of Green Gables, with distinctly PINK hair in two loose braids, wispy bangs, subtle freckles and clearly visible ROUND PRESCRIPTION GLASSES with transparent lenses. Original contemporary countryside-adventure clothing: sage-green short sleeved pinafore over cream blouse, practical dark shorts visible under short tunic, brown lace-up ankle boots, modest rose hair ties. Friendly expressive brown eyes, same youthful illustrated proportions as Kael, approximately four heads tall, readable silhouette. Crisp hand-drawn 2D game art, near-black outlines, flat cel-shaded color clusters, restrained tiny pixel-textured edges like reference, NO 3D, NO glossy painting. Exactly FOUR equal columns by FOUR equal rows, 16 full-body figures, portrait sheet 1536x2048 if possible, each equal 384x512 cell, all characters fully inside cells, same scale, generous transparent margins and identical foot baseline per row. Reading order row 1: four subtle idle frames facing right in 3/4 view, breathing and blinking. Row 2: four distinct consecutive walk poses facing RIGHT with alternating legs and opposite arms, contact/down/passing/up. Row 3: four consecutive empty-handed kite-line control gestures facing right: anticipate, reach, strong pull, recovery. Row 4: welcoming wave, thoughtful adjusting glasses, determined ready stance, cheerful fist-raised victory. Keep glasses, pink braided hair silhouette, face, outfit and body identical across all sixteen cells. Genuine transparent alpha background, no scenery, no grid lines, no text, no labels, no watermark, no kite or loose string crossing between cells.
