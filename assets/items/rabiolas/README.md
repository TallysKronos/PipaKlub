# Rabiolas na Dex

33 PNGs RGBA de 209 × 209 px, recortados sem redimensionamento da prancha aprovada pelo usuário. Arte gerada com image_gen; pacote de origem: pipa-rabiolas-v1.

assets/pipa-items.json associa cada item ao ID estável do Pipamon. assets/pipa-dex.json referencia seus itens por ID. O build publica os arquivos e gera URLs com hash; o servidor aceita somente arquivos listados no catálogo.

A Dex apresenta o catálogo de drops previstos para encontros selvagens. Nenhuma chance de drop foi inventada e nenhum item é concedido ao consultar a ficha. O sistema de encontros, sorteio, inventário de rabiolas e equipamentos não faz parte desta alteração. Nozinho tem item associado de companheiro, sem origem selvagem.

## Rabiola de Javali de Biscoito

34º item, cadastrado como origem de evento para invocação. PNG RGBA de 1254×1254, preparado com image_gen a partir da referência enviada pelo criador, preservado em resolução nativa. `imageSize` declara suas dimensões no catálogo; os 33 itens anteriores continuam em 209×209. O item usa o mesmo caminho de publicação e cache por hash. Ver INVOCACAO-JAVALI.md para migração, entrega administrativa e testes.
