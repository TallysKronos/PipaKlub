# Artes do menu — revisão 2D

Geradas com a ferramenta integrada de imagens, usando os sprites de Pipamon como referências. Seis PNGs individuais com transparência, sem recorte de atlas. Integrados com URLs contendo hash para renovação do cache.

Arquivos: club-collection-v2.png, club-trades-v2.png, club-summon-v2.png, club-farm-v2.png, club-profile-v2.png, club-history-v2.png em assets/ui/ no projeto e nesta pasta de entregas.

## Prompts finais

### collection

Use case: stylized-concept. Create ONE isolated game menu icon, square transparent PNG. The attached images are STYLE REFERENCES only, not edit targets. Match their 2D Pipamon sprite style: crisp near-black outer contour, angular cel shading in 2 or 3 flat color clusters, vivid warm colors, charming readable cartoon silhouette, slight pixel-cluster edges. Simple front facing game inventory icon, NOT painterly, NOT rendered 3D, no realistic texture, no soft lighting or gradients, no decorative background. One centered self contained composition with at least 15% empty transparent padding on every edge. No text, no letters, no additional icons or scattered objects. Subject: a small open wooden kite collection box holding three folded diamond kites in orange, leafy green and blue, with one short tidy ribbon. Simple chunky shapes, dark brown outlines, flat cel shaded colors.
