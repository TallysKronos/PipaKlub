# Criança — Lince de Cerco

Definido pelo autor: criar evo-line para o Lince de Cerco. Adulto aprovado preservado integralmente.

Proposta: Firma as patas enquanto descobre como puxar as linhas das pequenas bandeirolas. Herança: índigo, marfim, coral, linha lima, orelhas com terminais e focinho felino curto. O desenvolvimento muda cabeça, corpo e estrutura dos ombros: abas → bandeirolas → conjunto dobrável → grandes arcos separados.

Verbo: puxar. Limitação proposta: não sustenta alta tensão. Uma rabiola com dois terminais porta a mesma almática; fios operacionais não são outras almas. Nome de espécie, graus mecânicos, habilidades, requisitos e obtenção indefinidos.
