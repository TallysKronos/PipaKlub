# Papisco — base de overworld em 64×64

Base gerada via image_gen com o concept próprio como identidade e o Alvacordo v5 como referência de acabamento. Prompt em `prompt.txt`, geração preservada em `pose-gerada.png`. Importação para 64×64 no Aseprite, paleta limitada, alpha binário, contorno interno e corda vermelha recuperada. Fonte estática e ciclo preliminar de oito frames idle/oito caminhada preservados nesta pasta.

O autor gostou da base e solicitou versão 32×32 durante a produção. A entrega revisada está em `../overworld-32-v1/`. Os ciclos 64×64 ficaram como intermediários sem revisão independente final; não declarar integrados ou finalizados para produção.
