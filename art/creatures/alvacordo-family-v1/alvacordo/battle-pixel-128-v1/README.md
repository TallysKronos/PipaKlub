# Alvacordo — batalha 128×128

Adaptação estática da pose aprovada de batalha de 192×192. Canvas transparente 128×128, paleta de 24 cores, pivô sugerido (64, 123).

A base foi reduzida por vizinho mais próximo no Aseprite, mantendo as cores existentes: recorte de 118×164 para ocupação de 86×120, centralizada sem cortar os arcos. O olho recebeu um ajuste local de um pixel para recuperar o âmbar. Não é uma recuperação comprovada de grelha nem um redesenho integral pixel a pixel.

- `alvacordo-battle-128.png`: sprite nativo transparente.
- `alvacordo-battle-128.aseprite`: fonte editável; fundo de prévia oculto.
- `preview-branco-4x.png`: visualização ampliada sem suavização.
- `preview-transparente-4x.png`: ampliação transparente.
- `validacao.json`: medidas do PNG exportado.

As versões de 192×192 e suas animações permanecem nos diretórios anteriores. Esta entrega contém uma pose, sem integração no jogo.
