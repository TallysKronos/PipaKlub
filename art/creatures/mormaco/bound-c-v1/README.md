# Mormaço C · amarrado pelo Carretel Negro · V1

Desenvolvimento do estado de confronto do mesmo Mormaço C escolhido. A forma livre, a exploração de quatro opções e todas as reservas para outros Soulmonsters são preservadas sem sobrescrita.

Base narrativa: Bíblia, seções 2.3/2.4 e Ato 4. O Carretel Negro amarra e força obediência; a derrota desfaz o controle, sem morte do guardião. Isto não é uma evolução ou nova espécie.

Proposta visual: poucos cordões negros trançados com fio violeta, nó de controle central sobre a carapaça, bases dos gêiseres pressionadas e postura tensa. Água quente e vapor permanecem azuis/brancos, corpo magenta, placas roxas, ventre ocre e garras claras. Sem ferimentos gráficos ou corda estrangulando o pescoço.

Produção com image_gen, referência em `../model-c-v1/prancha-c-livre.png`; prompt integral em `prompt.txt`. Estado visual ainda para revisão, não aprovado automaticamente. Não é rig, spritesheet, chefe integrado, teste de combate ou alteração de mapa/save.
