Prompt usado: folha com seis sprites separados, corpo inteiro e margens transparentes amplas, leve vista superior em três quartos, proporção de quatro cabeças, linha fina, cores chapadas, sombra cel discreta, sem pixel art/textura/3D/texto/cenário.
