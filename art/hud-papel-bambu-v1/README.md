# HUD ilustrada — papel e bambu

Kit visual gerado para o PipaKlub. Esta versão contém as pranchas originais de assets, sem aplicação no jogo e sem publicação.

- `hud-molduras-barras-botoes.png`: 1536 × 1024, RGBA. Moldura de retrato, placa de jogador, relógio, placar, trilhos e preenchimentos de vida/energia, quatro estados de botão, slots de habilidade, divisor e marcadores de rodada.
- `hud-icones-combate.png`: 1254 × 1254, RGBA. Ataque, esquiva, linha, energia, seis rebicadas, guarda, crítico, pausa, opções, som e vitória.

A transparência foi conferida nos arquivos. A organização visual segue quatro colunas e quatro linhas, mas os limites ilustrados não correspondem a células rígidas: recortar e normalizar dimensões/estados antes de registrar um atlas de produção. Não usar divisão automática em células iguais.

Os interiores das molduras estão sem texto para receber os dados reais do jogo. Os prompts completos estão em `PROMPTS.md`.
