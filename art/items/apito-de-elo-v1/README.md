# Apito de Elo

Arte original gerada com imagegen integrado em fundo transparente, a partir
de `prompt.txt`, sem imagens externas. `source.png` conserva a saída integral;
o ícone no jogo é `godot/assets/ui/key-items/apito-de-elo.png`, 128 × 128.

Uso: item permanente recebido na missão **Um elo para a estrada**, com Zeca
e Lia na cidade. Inventário e banner usam o mesmo ícone. Sem créditos ComfyUI
de parceiro/API. A animação da montaria foi gerada separadamente no H3 local.
